## USB SQ Tool 1.5

On 2026-11-15, Windows Defender reported `Trojan:Win32/Pomal!rfn` for the supplied loose `Rockchip_USB_SQ_Tool_V1.5.exe` and quarantined it. The detection record reports that the program did not execute. The executable's earlier SHA-256 inventory value is `07219c1e5e254d5acba9853bb04e996702db8ad94abe8b4f46a9a3898d418d9a`.

This report is not a conclusive malware analysis; a false positive or another explanation has not been ruled out. The USB SQ 1.5 archive is withheld from the current branch and download index until its provenance and executable can be verified with the vendor. Do not disable antivirus or restore the quarantined program merely to follow the tutorial.

The package was present in an earlier repository commit before this detection was inspected. Removing the current file does **not** erase Git history. Do not retrieve the historical archive for use. The retained catalog hash identifies the withheld archive, not a safety approval. Original user-owned source archives were not modified.

The usage guide and original PDF remain available as documentation. Other packages have passed file-integrity and URL checks; these checks are not malware-free certifications or hardware tests.
